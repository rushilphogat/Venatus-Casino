# Gameplay and reveal audit — 17 November 2026

## Confirmed issues corrected

- Poker reveal, inline results and replay showed only two hole cards, omitting the five-card construction. All three now render the same authorized five-card evidence with Hole/Board labels; the cinematic lets players inspect each hand's community-card highlights. Unused hole cards are dimmed.
- Current-hand highlighting targeted every matching card ID in the document, including old replay cards. It is now scoped to the current board and own hand, and survives same-hand snapshot refreshes.
- Best-five display order followed input order. Cards now appear in rank/group order, including wheel ace last; a royal flush is named explicitly. Board-first evaluation avoids suggesting hole-card participation when the board itself is the best hand. Pot comparison rules are unchanged.
- Replaying a past result retained the current presentation state, potentially dismissing immediately or voting on an unrelated live hand. Replay presentation is isolated from live voting and timers.
- Replay navigation looked up a mutable history index after new results arrived. It now retains the selected result snapshot. Matching cached results are refreshed from authorized views; switching viewers clears cached evidence.
- Rummy never exposed its private drawn-card marker to the drawing player, so the visual cue could not work. It now sends the marker only during that player's discard phase. Drawing also clears the previous group analysis; discarding clears the marker.
- Dimming a 3D flip wrapper flattened its faces and could display the back. Only the front face is dimmed now. Dense desktop reveal layouts were compacted so awards remain readable; phone content scrolls within the dialog above fixed controls.
